# DesafioPractico1

Aplicacion Android desarrollada en Kotlin para resolver los ejercicios del desafio practico.

## Funcionalidades

- Calculo de promedio ponderado.
- Calculo de salario y descuentos.
- Calculadora con operaciones matematicas.
- Historial de operaciones de calculadora.
- Exportacion del historial.
- Notificaciones de resultados.

## Tecnologias
- Kotlin
- Android
- Gradle
- Android SDK
- Material Design

## Requisitos

- Android Studio
- JDK 11
- Android SDK 34
